# 📊 SQL Interview Prep — 7-Day Roadmap (100 Questions)

A structured, hands-on SQL practice plan for **Data Analyst / Data Scientist** interviews. It takes you from basic queries to window functions and real-world business problems in one week.

## 🗓️ Roadmap

| Day | Focus | Questions | Key Concepts |
|-----|-------|-----------|--------------|
| 1 | SQL Fundamentals | 1–15 | `SELECT`, `WHERE`, `DISTINCT`, `ORDER BY`, `LIMIT`, `NULL`, aliases |
| 2 | Aggregation & GROUP BY | 16–30 | `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING` |
| 3 | JOINs | 31–45 | `INNER`, `LEFT`, `RIGHT`, self join, multi-table joins |
| 4 | Subqueries, CTEs & CASE | 46–60 | Correlated subqueries, `EXISTS`, `IN`, CTEs, `CASE` |
| 5 | Window Functions | 61–75 | `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `LAG`, `LEAD`, `OVER()` |
| 6 | Real-World Problems | 76–90 | Duplicates, customer/order analysis, revenue analysis |
| 7 | Mock Interview | 91–100 | Nth-highest salary, streaks, MoM growth, customer report |

## 🗂️ Datasets Used

- `employees(employee_id, name, department_id, manager_id, salary)`
- `departments(department_id, department_name)`
- `locations`, `customers`, `orders`, `products` (for joins, sales and case-study problems)

## 🚀 How to Use

1. Follow one day at a time and write every query yourself.
2. Practice on any SQL engine (MySQL, PostgreSQL, SQLite).
3. Revise the "interview trap" notes at the end of each day.
4. On Day 7, set a **90-minute timer** and work with no notes.

## ✅ Benefits

- **Progressive learning:** each day builds on the previous one, from basics to advanced topics.
- **Interview-focused:** covers the questions most asked in analyst and data science interviews, such as Nth-highest salary, duplicates and top-N per group.
- **Strong core skills:** JOINs, aggregation and window functions are the most tested SQL areas.
- **Business relevance:** real-world scenarios such as customer churn, revenue trends and product performance mirror day-to-day analytics work.
- **Builds confidence:** writing queries without thinking about syntax, plus a timed mock day, prepares you for live coding rounds.
- **Portfolio ready:** solved queries can be published on GitHub to showcase your SQL skills.

## 🎯 Outcome

After 7 days you should be able to write clean, optimized queries, explain `ROW_NUMBER` vs `RANK` vs `DENSE_RANK`, choose between `WHERE` and `HAVING`, and solve end-to-end business problems under time pressure.

⭐ *Practice consistently, understand the logic behind each query, and don't just memorize patterns.*
